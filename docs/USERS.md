# ChainChit — Mainnet User Ledger

Ledger of verified mainnet users. Each row requires on-chain proof — link the
Stellar Expert account page or the first transaction hash per user.

**Status**: `onboarded` = funded + joined a group, `active` = ≥1 contribution or
bid transaction in current month, `churned` = no activity 30+ days.
